# 数据监控模块

## 引导式使用流程

登录后默认打开“开始使用”。可从零创建，或点击“用虚构品牌填写示例”（只填表，不自动写库）。

1. 创建页依次确认品牌、监测问句和回答来源。问句可用固定模板辅助填写，并以词面规则展示分类预览，不是大模型市场研究。项目与初始问句通过 `POST /api/v1/monitor-projects` 一次事务保存。
2. 保存后进入“运行监测”。方式一运行模拟演示，方式二导入已有回答；后者提供 UTF-8 CSV 模板及各列中文说明。
3. 完成后自动进入本次批次结果，不再要求用户手动切换来源寻找样本。指标有分母说明，原始证据保留展开核验入口。
4. “开始使用”的下一步随当前项目、启用问句和已完成批次变化，提供继续运行或查看最新结果入口。

示例始终标注为虚构或模拟。页面不会把模拟效果改称真实监测，也不会暗示已接入自主智能体。

迁入范围：原 GEO 数据监控的三页组织方式与筛选、表格、状态、详情和历史导航。公司项目、客户数据、公共模块密钥、积分、组织切换和付费发布不迁入。

## 已实现

- 数据监控项目库：项目名称、品牌、最新批次状态、创建日期筛选，服务端分页；启用问句数量；进入数据、设置与历史。
- 创建监测项目：对话外观的三步配置表单，包含品牌资料、问句预览和来源确认；公共平台显示未接入。
- 单次问句分析：选择当前项目启用问句运行独立模拟批次；分析记录按品牌、已保存问句、来源、状态分页筛选。
- 数据详情：按来源和批次统计样本、提及、推荐、显式编号分布，显示竞品和回答原文证据。
- 批次历史：时间、状态、数量、异常说明及批次详情入口。导入批次可能包含多个问句，与单问句模拟明确区分。
- 项目维护：修改名称、启停问句、查看批次状态；品牌背景资料以知识库文档新版本保存，不覆盖旧资料。品牌词典固定，防止已有提取证据被新词典解释。
- 页面页签可切换、关闭；列表支持双月日期范围选择和页码跳转。
- 分析详情弹窗：原始问句、模型回答、品牌识别与证据并排核验；品牌标签只对应当前选中回答。支持复制完整回答原文、收起或展开品牌证据、切换回答及刷新批次；窄窗口改为上下布局。未持久化的搜索引用明确显示不可验证。
- 数据看板：卡片指标、显式位置分布、日期趋势、来源分布和原始记录；时间、问句、模型可联动筛选，分页查看原文，可导出当前统计。未提供采集日期时使用入库日期，只绘制有样本日期，不补造趋势。

## 边界

### 页面组织

侧栏以可折叠的「GEO 数据监控」「内容创作」「企业知识库」分组组织已有页面，当前项目切换位于顶栏。桌面支持收起侧栏，窄屏通过菜单按钮展开导航。创建项目使用助手消息、确认气泡和三步校验表单，仍是本地规则引导，不是多 Agent 执行。

企业知识库支持按标题或来源筛选资料列表、查看已保存原文，以及展开资料录入和词面检索测试。文章区展示已有资料草稿的创建日期、审核状态和审核入口；新建草稿沿用固定摘录工作流，不表示已经实现大模型文章生成。

首页新增网格背景的大输入框、项目数据卡和业务入口；输入框下方提供百炼多智能体聊天及公开执行轨迹。它与原创建助手及文章区的固定摘录工作流分别实现，详见 `agent-chat.md`。首页数字来自当前项目：问句为启用数量，批次回答统计最近100批次（含模拟），草稿为最近最多100条，不是原站全量数据。

本轮外站访问停留在登录页，登录后页面的进一步核对待重新登录；菜单与创建助手的视觉调整依据此前用户提供的截图，不宣称已完整复刻所有外站页面。

界面统一使用蓝色表示操作和筛选选中状态，绿色保留成功语义，未提及率使用中性色而非错误红色。按钮执行中禁用并显示忙碌标记；CSV 导入先选择合法文件；空结果禁止导出。看板筛选加载时提示更新，失败保留上次结果并说明，不将旧结果标作新查询。重置看板仅清除日期、问句和模型，保留批次及来源。

真实或历史回答通过 CSV 导入，真实性由导入者核验；模拟适配器只验证流程。没有直连豆包、千问、元宝等公共平台，没有自动定时采集。

旧批次没有持久化完整执行问句快照。失败批次保留回答时可核对原文，没有回答时显示失败原因；等待或执行中的空批次暂不允许查看。运行监测页可重新运行当前启用问句，但这不是原批次的原样重试，不覆盖原始记录。

本版不提供删除、回收站或虚构的创建人、监测周期、关键词热度。后续若增加原任务重试、软删除或调度，先提供结构 SQL，执行范围仅独立 `brand_geo_rag_agent` 数据库，不修改公司主库或国家库，也不新增迁移文件。

接口：`GET /api/v1/monitor-projects`、`GET /api/v1/monitor-analyses`、`PATCH /api/v1/projects/{id}`、`GET /api/v1/monitor-batches/{id}/detail`、`GET /api/v1/projects/{id}/monitor-dashboard`、`GET /api/v1/projects/{id}/knowledge/documents/{document_id}`。其余流程复用已有问句、批次、导入和指标接口。看板不提供未经实现的情感分析或风险评级，规则推荐不代表模型真实推荐意图。
