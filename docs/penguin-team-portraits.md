# 四位角色的原图头像

当前使用用户提供的四企鹅合照，通过 CSS 圆形取景分别展示四个头像，不重绘、不改变原动画造型。原始文件完整保留在 `app/templates/assets/agents/penguin-team-reference.png`，首页角色卡与执行过程使用同一份坐标映射。

对应关系：前方中央是老大 Skipper（主管），后方高个子是科瓦斯基 Kowalski（检索），左下角是菜鸟 Private（工具），右侧是瑞科 Rico（摘要）。

当前完成的是原图头像展示，不是四张独立全身战斗插图。内置图像工具的单独提取请求被拦截，未产生可用文件，也没有改用其他模型。左上角也使用同一原图中的老大头像，不加西装和墨镜；先前的原创西装头像已停止使用，文件保留。

## 提取尝试的提示词

使用内置 image_gen，参考图为上述用户合照，`transparent_background=true`。每次只选择一个角色：

- Skipper：原图正前方中央、双翅交叉的矮壮企鹅。
- Kowalski：原图后方偏左、最高最瘦的企鹅。
- Private：原图最左下方、体型最小的企鹅。
- Rico：原图右侧、侧身伸展双翅的企鹅。

共同要求：仅提取目标角色，删除其余角色和白色背景；保持原角色外貌、姿态、头部形状、眼神、喙、身体比例、羽毛材质和原动画三维渲染效果，不改成原创、不添加服装道具；补齐少量被遮挡部位，全身居中、透明背景、不添加文字或水印。
