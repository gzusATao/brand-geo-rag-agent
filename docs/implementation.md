## 下一阶段

1. 完善持久任务及连接管理。已有MySQL结构SQL与独立初始化程序，不自动新增迁移，不操作公司主库或国家库。
2. 真实自然回答采集不得注入品牌知识库；记录模型、参数、提示词、Token用量和每次尝试。无配置时明确拒绝，不悄悄降级Mock。
3. 接入个人可控Dify知识库和工作流或等效实现。如需新增共享公共模块工作流Key，同步检查D:/projects/hlg-common-import配置映射；不写入或记录密钥。
4. 实现自主工具选择、受控生成、步数上限、失败Trace和证据不足提示，保留规则工作流作为对照。
5. 锁定人工测试集，做无检索/RAG/RAG+工具调用实验。Mock仅测试链路；不要求付费文章发布，也不推断公共模型收录因果效果。

首版没有国家平台列表，不以通用平台配置兜底；多国家功能不在毕设首版范围。
